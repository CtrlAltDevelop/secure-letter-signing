Signed, confidential letters

نامه بنویسید، برای مدیر بفرستید، تأیید یا اصلاح بگیرید و پاسخ امضاشده‌ی غیرقابل‌دستکاری دریافت کنید. کنار آن: وظیفه، پروژه و گانت، جلسه، گفتگو، نظرسنجی، CRM، مالی و فروش.

Write a letter, send it to the manager, get an approval or a revision request, and receive a tamper-evident signed reply. Plus tasks, projects with Gantt, meetings, chat, polls, CRM, finance and sales.

چرا؟

Why

امضای قابل‌راستی‌آزمایی

Verifiable signatures

تغییر یک حرف، امضا را نامعتبر می‌کند. هر امضا روی کل محتوا و سربرگ بسته می‌شود.

Change one character and the signature fails. Every seal covers the whole content and letterhead.

رمزگذاری در سرور

Encrypted at rest

متن نامه‌ها رمزشده ذخیره می‌شود؛ زنجیره‌ی هش برای ممیزی؛ هیچ‌چیز حذف نمی‌شود.

Letter bodies are stored encrypted, the audit log is a hash chain, and nothing is ever deleted.

میزبانی شخصی

Self-hosted

هر شرکت یک استقرار جدا با پایگاه‌داده، Redis و کلیدهای خودش؛ با Docker در چند دقیقه.

One company per deployment, with its own database, Redis and keys. Docker up in minutes.

امضا با PIN یا بیومتریک

PIN or biometric signing

اپ Flutter برای اندروید، iOS، macOS و ویندوز؛ درخواست امضا از دستگاه دیگر.

Flutter app for Android, iOS, macOS and Windows, with sign requests approved from another device.

نسخه‌ی کاملاً آفلاین

A fully offline edition

سه فایل HTML مستقل با ECDSA و AES-GCM، بدون هیچ درخواست شبکه.

Three self-contained HTML files using ECDSA and AES-GCM, with zero network requests.

فارسی و راست‌به‌چپ

Persian, RTL-first

رابط فارسی، تقویم جلالی و فونت وزیرمتن.

Persian UI, Jalali calendar and the Vazirmatn font.

جریان کار

How it works

کارمند می‌نویسد

Employee drafts

موضوع و متن با سربرگ شرکت، پیش‌نمایش و ارسال.

Subject and body on the company letterhead, preview, send.

مدیر تصمیم می‌گیرد

Manager decides

تأیید، نیاز به اصلاح (با توضیح) یا رد.

Approve, request a revision (with a note) or reject.

امضا و بازگشت

Signed reply

پاسخ مهرشده برمی‌گردد؛ نسخه‌های اصلاحی زنجیره‌ی قابل‌بررسی می‌سازند.

A sealed reply comes back; revisions form a verifiable chain.

Run it

git clone https://github.com/CtrlAltDevelop/secure-letter-signing
cd secure-letter-signing
make dev        # backend on http://localhost:8090, no Docker

# production, one brand per company
cp brands/.env.example brands/<brand>/.env
./build.sh <brand> up
